# Recompensa Pix — versão 0.2 com indicações demonstrativas

Inclui:
- Início, quiz, vídeos, carteira e nova seção de indicações.
- Botões para copiar código e compartilhar link demonstrativo.
- Avisos claros: não existe rastreamento real, comissão ou pagamento nesta versão.

## Limites importantes
O código de indicação é apenas demonstrativo. Não há autenticação, backend, banco de dados, rastreamento de cadastros ou sistema de comissão. O código não paga R$ 100 por instalação. Não prometa dinheiro sem uma campanha financiada.

## Publicação pelo celular
1. Extraia o ZIP no celular.
2. Entre em https://github.com/ e crie um repositório.
3. Envie todos os arquivos e pastas para o repositório.
4. Settings → Pages → Deploy from a branch → branch `main` → folder `/ (root)` → Save.
5. Abra a URL publicada e, no Chrome Android, use o menu ⋮ → Adicionar à tela inicial, se disponível.

## Como projetar um programa de indicação real
- Tornar o programa secundário ao conteúdo útil do app; não incentivar instalações artificiais ou avaliações.
- Definir ação qualificada real e transparente, em vez de pagar só por download.
- Ter um orçamento de comissão financiado por receita legítima e um limite por usuário.
- Usar backend para atribuir referências, validar conta nova, detectar fraude e registrar pagamentos.
- Publicar termos, regras de elegibilidade, limites, prazos e política de privacidade.
- Não depender de recrutamento em cadeia; qualquer bônus deve vir de receita real por atividade legítima.
- Consultar as políticas atuais da loja e dos provedores. O Google Play proíbe incentivos que manipulem instalações/avaliações; o Google AdMob não permite dinheiro direto como recompensa por anúncio recompensado. Verifique as políticas oficiais antes de monetizar.

## Segurança
Chaves secretas de pagamentos ficam apenas no backend. Nunca cobrar taxa antecipada para liberar saque. Nunca exibir saldo fictício como dinheiro real.
